关于我们

社会反假新闻系统

本系统旨在通过集体智慧帮助识别和打击假新闻。用户可以提交新闻，其他用户可以投票和评论，共同判断新闻的真实性。

系统功能

  • 浏览新闻列表，支持按真实性筛选
  • 查看新闻详情，包括完整内容和图片
  • 对新闻真实性进行投票
  • 添加评论和图片证据
  • 提交新的新闻供社区验证

如何使用

  1. 在首页浏览新闻列表，使用筛选功能查看特定类型的新闻
  2. 点击新闻卡片查看详情
  3. 在详情页面对新闻真实性进行投票并添加评论
  4. 通过"提交新闻"页面添加新的新闻供社区验证

我们相信，通过集体的智慧和协作，我们可以共同创造一个更真实的信息环境。
